**资料来源。** 本报告第三至六章与附录的全部事实来自本专题九份研究笔记（Lattice 历史、功能架构、能力案例、合同；Maven 历史、功能架构、能力案例、合同；合作与国家布局、集成对比），笔记于 2026-10-10 编写。引用的来源类型包括：美国政府与北约官方文件（国防部与战争部备忘录、主计长预算概览书、陆军/陆战队/海军新闻稿、DSCA 军售通知、NCIA 与 SHAPE 新闻稿、国会证词、白宫情况说明）、公司一手材料（Anduril、Palantir 新闻稿与博客，Palantir 向 SEC 提交的 10-K、10-Q 和季度财报）、主流防务与财经媒体（DefenseScoop、Breaking Defense、Defense News、Defense One、Reuters、Bloomberg、Janes 等）、智库与研究机构（CSIS、CSET、GAO）以及少量博客与聚合站。

**网页抓取受限。** 本轮调研环境中，WebFetch 与 curl 对绝大多数外部站点（defensescoop.com、breakingdefense.com、anduril.com、csis.org、wikipedia 等）返回 DNS 解析失败或代理 403，因此**大部分事实来自搜索引擎对原文的结果摘要，而非逐篇全文阅读**。具体影响有三：一是引文中的原话属"转述级"，个别措辞可能与原文有出入；二是文章标题在引注库中多依据 URL 与搜索摘要还原，可能与原标题存在细微差异；三是金额、日期等关键数字虽均有出处，但未与原文逐一核对，附录二列出了已知的冲突。

**唯一的一手代码证据。** 能够直接读取的只有 GitHub 上 Anduril 官方公开的 Lattice Python SDK（github.com/anduril/lattice-sdk-python，由 Lattice OpenAPI 规范自动生成）。第三章关于 Lattice 实体组件、五类模板、敌我属性、航迹关联、逐字段密级标注、任务生命周期、对象存储与视频接口的描述，直接依据该仓库的 reference.md 与类型定义文件，是本报告可靠性最高的部分。Palantir 本体与 Target Workbench 的描述则依据 Palantir 公开文档和产品资料的搜索摘要。

**证据分级。** 正文采用三档表述：**确认**指官方或一手来源、或多家主流媒体口径一致；**报道**指依据匿名消息源或单一媒体；**弱源**指博客、聚合站或投资分析类站点，仅作线索。凡"公司声明""分析性构建""推断"均在正文中明确标注。第四章（八）的"MSS→NGC2 数据层→Lattice 边缘"管线是分析性构建，不是官方确认的事实。

**金额口径。** 合同金额区分上限、已拨付和对外军售批准估值；企业协议是合同载体，其下任务订单不重复计算；外币按来源给出的换算值列示，未做统一汇率折算。

**主要缺口。** 本轮未检索到 CSIS、CNAS、RAND、War on the Rocks、Hudson 对 MSS 与 Lattice 组合的专门分析；未找到两系统之间的接口标准文件；未取得 USASpending/FPDS 中各合同的实际拨付记录；未覆盖中国、俄罗斯的对应系统。这些缺口应在后续调研中定向补充。
