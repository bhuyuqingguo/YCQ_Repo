## 内容概要

- 规模：正文与附录共 592 页（PDF），收录 168 个案例（岛屿防卫 21、周边港口 57、海上小岛 20、远海机动编组 42、海上交通线 28），参考文献约 1200 条；可信度 A 级 45、B 级 108、C 级 15。

- 按岛屿防卫、周边重要港口、海上小岛（含礁、平台、离岸设施）、远海机动编组四类场景编排，另附海上交通线关联案例。
- 每个案例：要素表、事件经过、配图、防御与效果、各方口径比对、简评，事实带上标引注，文末参考文献按 GB/T 7714 著录。
- 第七至九章：按空中/水面/水下/集群与异构/成本交换横向比较，攻防规律与综合研判，对我启示与开发方向建议（含"案例→试验想定"转化表）。
- 附录：全部案例总表、大事年表、术语对照、存疑事项清单、资料来源说明。

## 配图说明

容器网络无法直接下载 Wikimedia 等图源，docx/PDF 版目前只嵌入自绘图表。补图办法：

1. 在本地浏览器打开 `成品/…（配图采集清单）.html`，点“一键打包下载”，得到 `xiguang_imgs.zip`（内含 manifest.json）；
2. 把压缩包传回对话（或解压到仓库 `源稿与脚本/imgs/` 目录）；
3. 重新运行 `python3 源稿与脚本/build/make_all.py`，照片按案例自动嵌入并重排图号，成品输出到 `源稿与脚本/out/`。

## 重建

python3 源稿与脚本/build/make_all.py
